

Flashing and getting NXT up and running with python.


# NXT Firmware
Get the lastest version of the NXC firmware here: https://bricxcc.sourceforge.net/test_releases/index.html


# Flashing
Use the libnxt, which is available through apt:

```bash
sudo apt install libnxt
```

And run the `fwflash` program with the downloaded firmware.
